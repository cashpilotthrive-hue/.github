# Installation Guide
1. Install Docker, Node.js 22+, Python 3.12+, and Expo CLI.
2. Copy `.env.example` to `.env` and change secrets.
3. Run `docker compose up --build` from `gotradepal/`.
4. Open API docs at `http://localhost:8000/docs` and admin at `http://localhost:5173`.
5. Run mobile with `cd mobile && npm install && npm run start`.
